# Hlubina

Kooperativní roguelike do prohlížeče inspirovaný deskovou hrou SubTerra. Výprava sestupuje do opuštěné podzemní laboratoře, odhaluje chodby, hlídá stoupající vodu a hledá zařízení, které probudí portál ven.

- Hra pro jednoho (myš nebo ovladač) nebo lokální multiplayer pro 2–4 hráče na ovladače
- Tři obtížnosti (2–4 postavy), tři akty, plán laboratoře s volbou cesty
- Schopnosti, sošky, sérum, typy levelů a tabulka výprav

Hrát: https://lygames.cz/hry/hlubina/

Celá hra je jeden soubor `index.html`, stačí ho otevřít v prohlížeči (doporučeno Chrome nebo Edge, na ovladače nejlépe stažený soubor).
